# Greenden - Flower & Plant Shopping Website

## About the Project

Greenden is my third frontend development project, created as part of my Full Stack Web Development learning journey. It is a flower and plant shopping website designed using HTML5 and Tailwind CSS, with a focus on responsive layouts and a clean user interface.

## Features

- Responsive navigation bar
- Hero section with a promotional banner
- About section highlighting website features
- Best-selling flower and plant product cards
- Customer review section
- Newsletter subscription section
- Footer with social media icons
- Hover effects and Tailwind CSS styling

## Technologies Used

- HTML5
- Tailwind CSS
- Font Awesome Icons

## What I Learned

- Building web page layouts using Tailwind CSS utility classes
- Creating responsive designs using breakpoints
- Using Flexbox and CSS Grid
- Styling elements with spacing, colors, borders, and shadows
- Adding hover effects and animations
- Organizing a website into reusable visual sections

## Project Purpose

This project was developed for practice to improve my frontend development skills and gain hands-on experience with Tailwind CSS.

- Make product buttons interactive
- Implement newsletter form validation
- Improve accessibility and responsive behavior
